
# HYROX DAILY

Periódico digital dedicado al mundo de HYROX.

## Descripción

Este proyecto consiste en una página web inspirada en el diseño de un periódico digital. Incluye noticias sobre competiciones, atletas y actualidad de HYROX.

## Tecnologías utilizadas

- HTML5
- Bootstrap 5
- Visual Studio Code

## Estructura del proyecto

- index.html: página principal del periódico.
- images/: carpeta con las imágenes utilizadas.
